# 任务分诊标签

技能使用以下五种标准任务状态。本表将这些状态映射到本项目实际使用的标签名称。

| 技能中的标签 | 本项目的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 待评估：维护者需要判断任务的范围、价值和处理方式。 |
| `needs-info` | `needs-info` | 待补充信息：等待提出者补充复现步骤、需求或验收标准。 |
| `ready-for-agent` | `ready-for-agent` | 可交给 AI：需求已明确，可以交给 AI 助手实施。 |
| `ready-for-human` | `ready-for-human` | 需要人工处理：需要人的决策、操作或实现。 |
| `wontfix` | `wontfix` | 不予处理：已决定不实施。 |

技能提及某种任务状态时，使用本表对应的实际标签名称。

以后需要适配已有标签时，修改第二列。标签本身保留英文，说明使用中文。
