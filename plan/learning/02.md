## 启动数据库

安装并启动 Docker 后，在仓库根目录执行：

```bash
docker compose up -d
```

Compose 已提供本地开发默认配置：
| 连接项 | 默认值 |
| --- | --- |
| Host | localhost |
| Port | 5432 |
| Database | market_dashboard |
| User | market_dashboard |
| Password | stock_dev_password |

宿主机端口 `5432` 映射到容器内 PostgreSQL 的 `5432`。首次启动需要下载镜像并初始化数据库，等待片刻即可连接。

如需自定义配置，可选执行 `cp .env.example .env` 后编辑 `.env`。已有 `.env` 会覆盖默认值；本机 `.env` 不提交。

## 检查数据库

```bash
docker compose ps
```

状态显示 `healthy` 后可以连接。也可以直接执行 SQL：

```bash
docker compose exec postgres psql -U market_dashboard -d market_dashboard -c 'SELECT current_database(), current_user;'
```

## 停止与重启

停止：

```bash
docker compose down
```

重启：

```bash
docker compose restart
```

数据保存在独立命名卷 `market_bashboard_postgres_data` 中，停止或重建容器会保留数据。`docker compose down -v` 会删除数据卷。
