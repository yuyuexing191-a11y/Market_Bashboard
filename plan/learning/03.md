## 数据源

数据根目录：`/mnt/glusterfs/quantdata/tushare/`。这是本地历史数据，不应称为实时数据。

| 数据集 | 路径 | 字段 | 分区 |
| --- | --- | --- | --- |
| `stock_list` | `stock_list/*.parquet` | `symbol`、`name`、`area`、`industry`、`fullname`、`enname`、`cnspell`、`market`、`exchange`、`curr_type`、`list_status`、`list_date`、`delist_date`、`is_hs`、`act_name`、`act_ent_type` | 无日期分区 |
| `stock_daily_kbar` | `stock_daily_kbar/date=YYYY-MM-DD/*.parquet` | `symbol`、`date`、`open`、`high`、`low`、`close`、`volume`、`amount` | 按交易日 `date` 分区 |
| `stock_1min_kbar` | `stock_1min_kbar/date=YYYY-MM-DD/*.parquet` | `datetime`、`symbol`、`date`、`time`、`open`、`high`、`low`、`close`、`volume`、`amount` | 按交易日 `date` 分区 |

Parquet 是按列存储的数据文件格式，可直接查询文件。`date=YYYY-MM-DD` 目录是日期分区：检查某个交易日时，只需要读取对应目录中的文件。

OHLCV 指 `open`（开盘价）、`high`（最高价）、`low`（最低价）、`close`（收盘价）、`volume`（成交量）；日线按日、分钟线按分钟记录，`amount` 为成交额。分钟线另保留 `datetime`、`time`。当前证据没有确认 `volume`、`amount` 的计量单位，不能自行解释为股、手、元或其他单位。

## 股票池配置

[`config/stock_pool.csv`](../../config/stock_pool.csv) 固定 20 个股票代码。CSV 每行一只股票；`sector` 是本项目统一的行业大类，`source_industry` 保留源数据的原始行业。五类各 4 只：

- 金融：601318.SH、600030.SH、600036.SH、300059.SZ
- 消费：600519.SH、000858.SZ、000333.SZ、600887.SH
- 制造：300750.SZ、002594.SZ、601899.SH、600031.SH
- 医药：600276.SH、603259.SH、300760.SZ、300015.SZ
- 科技：300308.SZ、603986.SH、688981.SH、000063.SZ

选择体现行业代表性，固定后便于后续导入和测试复现。脚本核对上市状态和数据存在性，报告各股票日线成交量、成交额供人工检查；这些结果不构成“流动性较高”的量化证明。若需要流动性筛选，应先确认指标、窗口和阈值。

## 源数据检查与覆盖口径

```bash
uv run --with duckdb python scripts/check_source_data.py \
  --data-root /mnt/glusterfs/quantdata/tushare \
  --stock-pool config/stock_pool.csv
```

未指定 `--date` 时，脚本先取日线与分钟线日期分区交集，再从新到旧寻找两个数据集都包含全部 20 个配置代码的首个日期。这就是“共同覆盖日期最大值”，也是本阶段所谓的最新完整交易日。

这里的“完整”仅指股票池代码覆盖。存在分钟记录、甚至记录条数相同，均不证明每分钟连续无缺失、没有重复记录或源文件已经写完。

指定日期并输出 JSON：

```bash
uv run --with duckdb python scripts/check_source_data.py \
  --data-root /mnt/glusterfs/quantdata/tushare \
  --stock-pool config/stock_pool.csv \
  --date 2026-10-09 --format json
```

`--date` 只检查指定日期，不回退；`--format text` 是默认的人类可读输出，`--format json` 适合其他程序读取。报告中的 Decimal 数值在输出边界转换为浮点数用于展示，不承诺保留任意精度 Decimal 的全部有效位。

测试命令使用临时测试数据，不改动真实源数据：

```bash
uv run --with duckdb --with pytest python -m pytest tests/test_check_source_data.py -q
```

## 学习结果

- Parquet 可按文件查询，日线和分钟线使用 `date=YYYY-MM-DD` 目录分区。
- OHLCV 描述价格与成交量，字段存在不代表已确认计量单位。
- 股票池是固定项目配置，共同覆盖日期用于复现本阶段检查，不证明分钟连续性或量化流动性。
- Compose 在本阶段准备数据库环境，后续通过迁移建表和导入。
- 验证结论引用真实证据，课程编号与 GitHub 编号分开，人工创建并合入 PR。
